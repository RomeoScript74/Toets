WEEK 12 Virtual Private Networking (VPN)
Wat is VPN en wie doet wat?
💡 VPN = een beveiligde verbinding van buiten naar binnen het netwerk
- RRAS1 = de VPN server (wacht op verbindingen van buiten)
- SRV1 of PC1 = de VPN client (maakt verbinding van buiten)
Stap 1 — RRAS1 instellen als VPN server
💡 Je zet RRAS1 aan als remote access server zodat hij VPN verbindingen kan ontvangen
  1. Tools → Routing and Remote Access
  2. Rechtermuisklik op RRAS1 → All Tasks → Stop (service stoppen)
  3. Rechtermuisklik → Properties
  4. General tab → vink aan: IPv4 Remote access server
  5. Verander naar LAN and demand-dial routing → Apply
Stap 2 — IP pool instellen
💡 Dit zijn de IPs die VPN clients krijgen als ze verbinden. Ze mogen niet overlappen met andere IPs in je netwerk!
  1. Klik op tabblad IPv4
  2. Kies Static address pool
  3. Klik Add
  4. Start: 172.16.1.201 → End: 172.16.1.210
  5. OK → dan RRAS service herstarten
Stap 3 — Ports configureren
💡 Ports zijn de "deuren" waar VPN verbindingen binnenkomen. Je moet aangeven welke soort VPN verbindingen zijn toegestaan
  1. In RRAS → klik op Ports in de linkerkolom
  2. Rechtermuisklik → Properties
  3. Klik op WAN Miniport (PPTP) → Configure
  4. Vink aan: ✅ Remote access connections (inbound only)
  5. Vink aan: ✅ Demand-dial routing connections
  6. OK
  7. Herhaal voor WAN Miniport (SSTP) als je SSTP ook wilt
⚠️ Onder "Used by" moet RAS/Routing staan — anders werkt VPN niet
Stap 4 — Gebruiker toegang geven
💡 Standaard heeft niemand VPN toegang. Je moet dit per gebruiker instellen in Active Directory
  1. Ga naar DC1
  2. Tools → Active Directory Users and Computers
  3. Zoek de gebruiker op → rechtermuisklik → Properties
  4. Klik op tabblad Dial-in
  5. Bij Network Access Permission kies: Allow access
  6. OK
Stap 5 — VPN client instellen (op SRV1 of PC1)
💡 Dit maak je de VPN verbinding aan op de client computer. Het internet address is het IP van RRAS1 aan de buitenkant
  1. Rechtermuisklik netwerk icoon → Open Network & Internet settings
  2. Klik VPN → Add a VPN connection
  3. Provider: Windows (built-in)
  4. Connection name: PPTP-VPN
  5. Server name: 172.16.2.251 (extern IP van RRAS1)
  6. VPN type: PPTP
  7. Username + password invullen
  8. Save → Connect
⚠️ Als verbinding mislukt → check firewall op RRAS1:
netsh advfirewall firewall add rule name="PPTP" protocol=TCP dir=in localport=1723 action=allow
netsh advfirewall firewall add rule name="GRE" protocol=47 dir=in action=allow
VPN Protocol vergelijking
  • PPTP — makkelijkst maar onveilig (poort 1723)
  • L2TP/IPsec — veiliger, gebruikt pre-shared key (poort 1701)
  • SSTP — via HTTPS poort 443, werkt door firewalls
  • IKEv2 — snel en stabiel, goed voor mobiel
💡 SSTP werkt het best door NAT/firewall heen want poort 443 is altijd open
⚠️ PPTP nooit gebruiken in productie — te makkelijk te hacken!

VyOS VyOS Router configureren
Basis — Hoe werkt VyOS?
💡 VyOS is een Linux router. Je typt commando's in de terminal. Er zijn twee modi:
- Normale modus → alleen bekijken
- Configuratie modus → instellingen wijzigen (na "configure")
configure ← ga naar configuratie modus (prompt wordt #)
commit ← activeer de wijzigingen
save ← sla op zodat het na herstart nog werkt
exit ← verlaat configuratie modus
show interfaces ← bekijk alle interfaces en IPs
show ip route ← bekijk de routingtabel
IP adressen instellen op interfaces
💡 Elke interface krijgt een IP in het netwerk waar hij op zit. Verander de IPs naar wat de opdracht vraagt!
configure
set interfaces ethernet eth0 address 172.16.3.252/24 ← eth0 = Leased netwerk (verbinding met RRAS1)
set interfaces ethernet eth1 address 192.168.5.252/24 ← eth1 = Amersfoort netwerk (intern LAN)
set interfaces ethernet eth2 address 10.13.14.252/24 ← eth2 = DMZ2 netwerk
set interfaces ethernet eth3 address dhcp ← eth3 = NAT/internet (krijgt automatisch IP)
commit && save
⚠️ Welke eth bij welk netwerk hoort → controleer MAC adressen in VMware Settings!
RIP Routing instellen
💡 RIP zorgt dat VyOS automatisch routes uitwisselt met RRAS1. Je geeft op welke netwerken VyOS kent. Verander de netwerken naar wat de opdracht vraagt!
configure
set protocols rip network 172.16.3.0/24 ← Leased netwerk (richting RRAS1)
set protocols rip network 192.168.5.0/24 ← Amersfoort netwerk
set protocols rip network 10.13.14.0/24 ← DMZ2 netwerk
commit && save
💡 Internet interface (eth3/NAT) NIET toevoegen aan RIP!
NAT instellen (internet voor interne netwerken)
💡 NAT zorgt dat computers in het interne netwerk via VyOS internet kunnen gebruiken. Elke intern netwerk krijgt een eigen regel. Verander eth3 naar je internet interface en de netwerken naar wat de opdracht vraagt!
configure
set nat source rule 100 outbound-interface eth3 ← eth3 = internet kant
set nat source rule 100 source address '192.168.5.0/24' ← intern netwerk
set nat source rule 100 translation address masquerade ← vertaal naar extern IP
set nat source rule 200 outbound-interface eth3
set nat source rule 200 source address '10.13.14.0/24'
set nat source rule 200 translation address masquerade
commit && save
Default route instellen (internet)
💡 Dit zegt: "al het verkeer dat nergens anders naartoe kan, stuur naar het internet". De gateway is het IP van VMware NAT (192.168.220.2 of vergelijkbaar)
set protocols static route 0.0.0.0/0 next-hop 192.168.220.2 distance 1
commit && save
