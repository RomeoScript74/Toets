  1. ADUC → gebruiker → Properties → tabblad Dial-in
  2. Network Access Permission: Allow access
VPN client instellen (Windows 10)
  1. Settings → Network & Internet → VPN
  2. Add a VPN connection
  3. Provider: Windows (built-in)
  4. Server: IP adres van RRAS
  5. VPN type kiezen (PPTP/SSTP/IKEv2)
  6. Username & password invullen
  7. Save → Connect
VPN Protocol vergelijking
  • PPTP — oud, onveilig (MS-CHAPv2 kwetsbaar)
  • L2TP/IPsec — veiliger, gebruikt pre-shared key
  • SSTP — via HTTPS (443), werkt door firewalls
  • IKEv2 — snel, stabiel, modern
💡 SSTP werkt het best door NAT/firewall heen
⚠️ PPTP nooit gebruiken in productie!
Firewall regels voor VPN
netsh advfirewall firewall add rule name="PPTP" protocol=TCP dir=in localport=1723 action=allow
netsh advfirewall firewall add rule name="GRE" protocol=47 dir=in action=allow
PLF08 Oefentoets — Routing tussen netwerken (op niveau)
Logica — begrijp dit eerst!
  • Core1 en DC1 zitten op verschillende netwerken
  • RRAS1 moet op beide netwerken een adapter hebben
  • Dan pas kan RRAS1 verkeer doorsturen
Volgorde: 1) Adapters in VMware → 2) IPs instellen → 3) RRAS installeren → 4) Routing aanzetten
Stap 1 — VMware instellen (buiten VM)

  • RRAS1 Settings → Add → Network Adapter → NAT (VMnet8)
  • Core1 Settings → Network Adapter → Custom VMnet2
Stap 2 — IP instellen op RRAS1
💡 Eerst uitzoeken welke adapter VMnet2 is met Get-NetAdapter

PLF12 OpenVPN op Rocky Linux — Server & Client
Stap 1 — Repos fixen & Software installeren
💡 Dit herstel je de software bronnen zodat je pakketten kunt installeren. Altijd als eerste doen op Rocky Linux!
sudo rm -f /etc/yum.repos.d/Rocky-*
sudo dnf reinstall rocky-repos --nogpgcheck --repofrompath base,https://dl.rockylinux.org/pub/rocky/8/BaseOS/x86_64/os/ -y
sudo dnf install epel-release -y
sudo dnf install openvpn easy-rsa -y
💡 Als repos leeg zijn: sudo rpm -ivh --nodeps https://dl.rockylinux.org/pub/rocky/8/BaseOS/x86_64/os/Packages/r/rocky-repos-8.10-1.8.el8.noarch.rpm
Netwerk instellen op Rocky Linux
💡 Eerst kijken welke adapters je hebt en hoe ze heten:
ip addr ← laat alle adapters zien, noteer de namen (bijv. ens160, ens224)
💡 Vast IP instellen op ens160 — verander 192.168.1.10 naar het IP uit de opdracht!
sudo nmcli con mod ens160 ipv4.addresses 192.168.1.10/24 ipv4.method manual
sudo nmcli con down ens160 && sudo nmcli con up ens160 ← adapter herstarten zodat IP actief wordt
💡 Tweede adapter (NAT/internet) instellen op DHCP — verander ens224 naar de naam van jouw tweede adapter!
sudo nmcli con add type ethernet ifname ens224 con-name ens224 ipv4.method auto && sudo nmcli con up ens224
ping 8.8.8.8 ← testen of internet werkt
Stap 2 — EasyRSA instellen (op server)
💡 Dit kopieert de certificaat-tool naar de OpenVPN map
sudo cp -rp /usr/share/easy-rsa/3.0/ /etc/openvpn/server/easyrsa3.0
sudo cp -p /usr/share/doc/easy-rsa/vars.example /etc/openvpn/server/easyrsa3.0/vars
💡 Dan de organisatiegegevens aanpassen — de toets geeft je de exacte waarden!
sudo nano /etc/openvpn/server/easyrsa3.0/vars
💡 Pas aan in vars (# weghalen):
set_var EASYRSA_REQ_COUNTRY "NL"
set_var EASYRSA_REQ_PROVINCE "Utrecht"
set_var EASYRSA_REQ_CITY "Utrecht"
set_var EASYRSA_REQ_ORG "Institute for ICT"
set_var EASYRSA_REQ_EMAIL "admin@ict.test"
Stap 3 — Certificaten aanmaken (op server)
💡 Dit maakt alle sleutels en certificaten aan die VPN server en client nodig hebben
cd /etc/openvpn/server/easyrsa3.0 ← ga naar de juiste map
./easyrsa clean-all ← mappen klaarmaken
./easyrsa gen-dh ← Diffie-Hellman sleutel aanmaken (duurt lang, normaal!)
./easyrsa build-ca ← Root certificaat aanmaken (vraagt om wachtwoord en naam)
./easyrsa build-server-full server1 nopass ← server certificaat zonder wachtwoord
./easyrsa build-client-full client1 ← client certificaat (verander client1 naar hostnaam van client!)
openvpn --genkey --secret /etc/openvpn/server/ta.key ← extra beveiligingssleutel
⚠️ client naam = hostname van rocky2. Controleer met: hostname
Stap 4 — Certs kopiëren naar client
💡 De client heeft de sleutels van de server nodig. We kopiëren ze via het netwerk naar /tmp op de client. Verander gebruiker naar jouw Linux gebruikersnaam en IP_CLIENT naar het NAT IP van rocky2!
sudo scp -p /etc/openvpn/server/ta.key /etc/openvpn/server/easyrsa3.0/pki/ca.crt /etc/openvpn/server/easyrsa3.0/pki/*/client1.{crt,key} gebruiker@IP_CLIENT:/tmp
Stap 5 — Server configureren
sudo nano /etc/openvpn/server/server.ovpn
💡 Inhoud server.ovpn:
port 1194
proto udp
dev tun
ca easyrsa3.0/pki/ca.crt
cert easyrsa3.0/pki/issued/server1.crt
key easyrsa3.0/pki/private/server1.key
dh easyrsa3.0/pki/dh.pem
tls-auth ta.key 0
server 10.31.33.0 255.255.255.0
ifconfig-pool-persist ipp.txt
push "redirect-gateway def1 bypass-dhcp"
keepalive 10 120
max-clients 2
user nobody
group nobody
persist-key
persist-tun
status openvpn-status.log
verb 3
sudo firewall-cmd --add-service=openvpn --permanent; sudo firewall-cmd --reload
sudo openvpn --cd /etc/openvpn/server --config server.ovpn
Stap 6 — Client configureren (op rocky2)
sudo dnf install epel-release -y && sudo dnf install openvpn -y
sudo mv /tmp/ta.key /tmp/ca.crt /tmp/client1.* /etc/openvpn/client
sudo chown root:root /etc/openvpn/client/{ta.key,ca.crt,client1.key,client1.crt}
sudo chmod u=r,o-rwx /etc/openvpn/client/{ta.key,ca.crt,client1.key,client1.crt}
sudo nano /etc/openvpn/client/client1.ovpn
💡 Inhoud client.ovpn:
client
dev tun
proto udp
remote IP_VPN_SERVER 1194
resolv-retry infinite
nobind
user nobody
group nobody
persist-key
persist-tun
ca ca.crt
cert client1.crt
key client1.key
remote-cert-tls server
tls-auth ta.key 1
verb 3
sudo openvpn --cd /etc/openvpn/client --config client1.ovpn
Stap 7 — IP Forwarding (routing via VPN)
sudo sysctl -w net.ipv4.ip_forward=1
echo "net.ipv4.ip_forward=1" | sudo tee -a /etc/sysctl.conf
sudo firewall-cmd --direct --add-rule ipv4 filter FORWARD 0 -i tun+ -j ACCEPT --permanent
sudo firewall-cmd --direct --add-rule ipv4 nat POSTROUTING 0 -o ens160 -j MASQUERADE --permanent
sudo firewall-cmd --reload
💡 Vervang ens160 door de interface richting het interne netwerk
